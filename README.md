# VeroRun Professional Edition

**VeroRun 专业版（官网建站）** —— 激活后解锁 13 个内置插件。

本仓库为专业版落地页，由 `sync-to-pro` CI 流水线维护，**仅包含本说明文档**（不含任何代码）。专业版内核从 `verorun-standard` 获取，插件通过内置插件商店安装。请勿手动推送本仓库。

---

## English

## Overview

The Professional Edition turns VeroRun into a full website platform. Activating the Pro edition unlocks 13 bundled plugin entitlements, which are installed on demand from the built-in plugin store — **no plugin is bundled in any distribution**.

Bundled plugin entitlements (Pro):

- `site_builder`, `analytics`, `visitor_profile`, `vault`, `health_check`
- `oauth_config`, `email`, `site_domains`, `im_gateway`, `sms`
- `captcha_embedded`, `chatbot`, `memory_engine`

## Getting Started

1. Deploy the core from `verorun-standard`.
2. Activate the Pro edition in the admin console.
3. Install the unlocked plugins from **Admin → Plugins → Store**.

## 中文

## 概述

专业版将 VeroRun 打造成完整官网建站平台。激活专业版后解锁 13 个内置插件授权，插件通过内置插件商店按需安装（**任何发行版均不捆绑插件**）。

专业版内置插件授权清单：

- `site_builder`（站点构建）、`analytics`（数据分析）、`visitor_profile`（访客画像）、`vault`（备份）、`health_check`（健康检查）
- `oauth_config`（第三方登录）、`email`（邮件）、`site_domains`（子域名）、`im_gateway`（消息网关）、`sms`（短信）
- `captcha_embedded`（验证码）、`chatbot`（AI 客服）、`memory_engine`（Agent 记忆）

## 快速开始

1. 从 `verorun-standard` 部署内核。
2. 在管理后台激活专业版。
3. 在 **管理后台 → 插件 → 商店** 安装已解锁的插件。
