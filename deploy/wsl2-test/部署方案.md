|---|---|---|

## 三、拟执行命令

部署由脚本内部 `do_install` 完成：
1. 安装系统依赖（nginx、postgresql、python3.12 venv 等）
2. 创建 guxiao 工作目录、克隆 verorun-code 到 `/home/guxiao/verorun`
3. venv + 全量依赖
4. 生成 `.env`（自动 secrets）
5. 写 systemd 服务（verorun-main/auth/admin/health/guardian）
6. 配置 nginx 反代
7. DB 迁移 + seed（管理员 guxiao）
8. VR_EDITION=official + token 验签
9. lan 模式自动自签 HTTPS 证书

**核心命令（一旦执行无法中途回退 UI 层面，属正式落地）：**

```bash
cd /home/guxiao/verorun-deploy/deploy
sudo env GIT_REPO=git@gitee.com:fanjumin/verorun-code.git \
  ./install-official.sh oneshot \
  --region=cn \
  --domain= \
  --admin-user=guxiao \
  --admin-pass=<自动生成>
```

> 说明：脚本内部 `_official_resolve_git_source` 会自动用 guxiao 的 key 探测源；若走 gitee 顺畅则直接克隆。

## 四、风险与回滚

| 风险 | 影响 | 缓解/回滚 |
|---|---|---|
| 会安装 nginx/postgresql 系统包 | WSL 内新增服务 | 可 `uninstall.sh` 完整卸载 |
| 克隆 ~60MB 私库 | 网络耗时 | gitee 已授权，失败可切本地 bundle 中继 |
| 密码仅显示一次 | 丢失需重置 | 完成后我立即记录，或 `install.sh seed` 重置 |
| 系统包 apt 安装需联网 | 可能慢 | WSL 已有 aliyun/docker 源记录 |

**完整卸载（需要时）：**
```bash
sudo env VR_UNINSTALL_YES=1 bash /home/guxiao/verorun/deploy/uninstall.sh
```
> 官方版会移除 public 脚本；uninstall.sh 在 verorun-code 仓库内，克隆后即存在。

## 五、验收标准（部署后）

1. `systemctl status verorun-*` 全部 active
2. 自签 HTTPS：`https://127.0.0.1` 或 WSL IP 可访问
3. nginx 反代正常（无 502）
4. admin 后台登录（guxiao + 生成的密码）
5. `.env` 含 `VR_EDITION=official`

---

> **确认点：** 是否按本方案在 WSL2 (Ubuntu24) 上执行官方版 oneshot 部署？执行后将对 WSL 内安装 nginx/postgresql 等系统服务并克隆私库，属不可逆的正式部署。
