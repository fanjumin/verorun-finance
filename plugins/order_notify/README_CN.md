# 订单通知 (order_notify)

## 概述

订单通知（order_notify）是 VeroRun 基于事件系统的自动订单通知插件。插件通过监听订单生命周期中的关键事件（下单、支付成功、发货、退款、取消、完成），自动触发相应的通知逻辑，确保用户和管理员能够及时收到订单状态变更信息。

## 功能特性

- **事件驱动架构**：基于 VeroRun 事件系统，监听 6 个订单生命周期事件
- **全生命周期覆盖**：覆盖从下单到完成的完整订单流程
- **自动通知触发**：事件触发后自动执行通知逻辑，无需手动调用
- **独立数据库**：使用独立的 SQLite 数据库存储通知记录
- **轻量级设计**：插件模块精简，仅包含数据模型和事件监听逻辑

## 架构设计

### 数据库策略

插件使用**独立数据库** `data/order_notify.db`（SQLite）。

### 事件监听架构

```
┌─────────────────────────────────────────────────────────────┐
│                     VeroRun 事件总线                          │
└─────────────────────────────┬───────────────────────────────┘
                              │
          ┌───────────────────┼───────────────────┐
          ▼                   ▼                   ▼
┌──────────────────┐ ┌────────────────┐ ┌──────────────────┐
│  order/created   │ │  order/paid    │ │  order/shipped   │
│  (下单)           │ │  (支付成功)    │ │  (发货)           │
└────────┬─────────┘ └───────┬────────┘ └────────┬─────────┘
         │                   │                    │
         ▼                   ▼                    ▼
┌──────────────────┐ ┌────────────────┐ ┌──────────────────┐
│ order/refunded   │ │order/cancelled │ │ order/completed  │
│ (退款)            │ │ (取消)          │ │ (完成)            │
└────────┬─────────┘ └───────┬────────┘ └────────┬─────────┘
         │                   │                    │
         └───────────────────┼────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────┐
│                    __init__.py                                │
│             (事件监听器注册与通知分发)                           │
└─────────────────────────────┬───────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    models.py                                  │
│            (通知记录存储 / data/order_notify.db)                │
└─────────────────────────────────────────────────────────────┘
```

### 监听的 Hook 事件

| 事件 | 触发时机 | 通知行为 |
|------|----------|----------|
| `order/created` | 用户下单 | 发送下单成功通知 |
| `order/paid` | 支付成功 | 发送支付成功通知 |
| `order/shipped` | 商家发货 | 发送发货通知（含物流信息） |
| `order/refunded` | 退款完成 | 发送退款通知 |
| `order/cancelled` | 订单取消 | 发送取消通知 |
| `order/completed` | 订单完成 | 发送完成通知 |

## 安装与启用

### 安装

插件已包含在 VeroRun 的默认插件目录中，无需额外安装步骤。

### 启用

1. 在 VeroRun 管理后台 "插件管理" 页面中启用订单通知插件
2. 插件启用后，6 个事件监听器将自动注册到事件总线
3. 当订单状态变更事件触发时，插件自动执行通知逻辑

## 配置说明

在 `plugin.json` 中配置以下参数：

```json
{
  "name": "order_notify",
  "database": {
    "type": "sqlite",
    "path": "data/order_notify.db"
  },
  "notifications": {
    "enabled_events": [
      "order/created",
      "order/paid",
      "order/shipped",
      "order/refunded",
      "order/cancelled",
      "order/completed"
    ],
    "channels": ["email", "site_message"]
  }
}
```

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `database.type` | 数据库类型 | `sqlite` |
| `database.path` | 数据库文件路径 | `data/order_notify.db` |
| `notifications.enabled_events` | 启用的通知事件列表 | 全部 6 个事件 |
| `notifications.channels` | 通知渠道列表 | `email, site_message` |
