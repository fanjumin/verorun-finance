# Product Reviews (reviews)

## 概述

Product Reviews（商品评价）是 VeroRun 的商城评价插件，允许用户对已购商品进行打分、撰写评价并晒图，同时提供评价审核与舆情分析能力。插件监听订单支付完成事件（`order.paid`），引导用户对已购商品进行评价。

## 功能特性

- **打分评价**：用户按 1-5 星为商品打分并撰写文字评价
- **晒图**：支持评价附带商品图片
- **评价审核**：提供评价审核（moderation）管理界面，可控制评价展示
- **舆情分析**：基于评价内容进行情感/舆情分析
- **事件驱动**：监听 `order.paid` 事件，自动引导已购用户评价
- **购买校验**：`review/validate` Hook 校验评价者是否为真实购买用户

## 安装与启用

### 安装

插件已包含在 VeroRun 的默认插件目录中，无需额外安装步骤。

### 启用

1. 在 VeroRun 管理后台 "插件管理" 页面中启用 Product Reviews 插件
2. 用户在购买完成后可在用户中心对商品进行评价
3. 管理员可在 "Business Center" > "Reviews Moderation" 中审核评价

## API 端点

### 提供的 Hook

| Hook 标识符 | 说明 |
|-------------|------|
| `review/validate` | 校验用户是否可评价（购买校验） |

### 监听的 Hook

| Hook 标识符 | 说明 |
|-------------|------|
| `order.paid` | 订单支付完成，触发评价引导 |

### 仪表盘统计

- 评价总数 / 平均评分 / 好评率 / 24h 新增评价 / 带图评价数

## 依赖关系

### 内部依赖

- **shop** 插件：商品与订单数据（`shop.product.read`）
- VeroRun 核心框架：Hook 系统、事件总线
