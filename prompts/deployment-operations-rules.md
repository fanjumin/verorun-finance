# 易站智能 - 部署与运维规范

**版本**：v2026.05  
**优先级**：高（生产环境稳定性）

所有部署、运维、服务器配置相关的任务，必须严格遵守以下规范，确保平台稳定、高可用、可监控。

### 1. 部署原则
- 采用**零停机部署**思维（蓝绿部署或滚动更新）
- 使用 Docker + Docker Compose 或 Kubernetes（根据规模选择）
- 所有服务必须支持环境变量配置（.env 文件不提交 Git）
- 关键服务（auth、platform、agent 等）应支持独立伸缩

### 2. 环境分离
- 严格区分开发环境（development）、测试环境（staging）、生产环境（production）
- 生产环境禁止使用调试模式（DEBUG=False）
- 生产环境必须强制启用安全设置（HTTPS、CSP、Rate Limiting 等）

### 3. 监控与可观测性
- 必须接入监控系统（Prometheus + Grafana 推荐）
- 核心指标必须监控：
  - 数据库连接数、慢查询、CPU/内存/磁盘
  - API 响应时间、错误率
  - Redis 队列积压情况
  - Agent 矩阵任务成功率
- 配置告警机制（关键服务异常、登录异常、数据库连接数过高时通知）

### 4. 日志管理
- 所有服务统一日志格式
- 敏感信息脱敏（密码、API Key、手机号等）
- 重要操作必须记录审计日志（用户ID、操作时间、IP、行为）
- 日志保留策略：重要日志长期保存，一般日志保留 30-90 天

### 5. 备份与恢复
- 数据库每日自动备份
- 重要配置定期备份
- 制定灾难恢复（Disaster Recovery）方案

### 6. 安全运维要求
- 定期更新系统依赖和安全补丁
- 使用 WAF 或 Cloudflare 等防护
- API Key、数据库密码等敏感信息严禁硬编码
- 生产环境必须启用 HTTPS

### 7. 修改部署相关配置时的要求
- 任何部署、配置、运维相关的修改必须先输出详细方案
- 方案需包含：变更影响、回滚计划、测试验证步骤
- 生产环境变更必须谨慎，建议先在 staging 环境验证
