# 易站智能 - 安全与合规规范

**版本**：v2026.05  
**优先级**：最高（安全相关任务）

平台涉及金融数据、API Key、本地 Agent 授权、用户隐私等敏感内容，必须将安全与合规放在绝对优先位置。

### 1. 核心安全原则
- **安全第一**：任何功能实现都必须优先考虑安全风险
- **最小权限原则**：用户和 Agent 只拥有必要的最小权限
- **零信任原则**：不默认信任任何请求或 Agent

### 2. 认证与授权安全
- 密码必须强加密存储（bcrypt / Argon2）
- API Key 必须哈希存储，且支持轮换、撤销、过期时间
- Session / Token 必须设置合理的有效期和安全标记（HttpOnly、Secure、SameSite）
- 登录后密码修改必须强制所有设备下线
- 关键操作（修改密码、创建 API Key、财务操作等）必须二次确认或验证码验证

### 3. 数据隐私与合规
- 严格遵守数据最小化原则（不收集不必要的用户数据）
- 用户交易数据、持仓信息严禁上传或存储在服务器
- 必须准备并维护《隐私政策》、《服务条款》、《API 服务协议》等合规文档
- 支持用户数据导出和删除权利（GDPR/CCPA 要求）

### 4. 常见安全防护
- 所有用户输入必须进行严格验证和清理（防止 XSS、SQL 注入等）
- 重要接口必须有速率限制（Rate Limiting）
- 敏感操作必须记录审计日志（谁、在什么时间、做了什么）
- 防止 API Key 泄露风险（不在前端明文暴露过长时间）

### 5. Agent 安全要求
- Agent API Key 必须与 Human User 强绑定
- 子 Agent 执行任务时必须经过主 Agent 权限检查
- 禁止 Agent 直接访问敏感数据库或核心配置

### 6. 修改安全相关功能时的严格要求
- 任何涉及安全、认证、权限、隐私的修改**必须先输出详细安全方案**，经用户确认后才能执行
- 修改后必须列出新增的安全风险点和防护措施
- 重要变更建议进行代码审查

### 7. 合规文档维护
- 定期检查并更新隐私政策、服务条款等法律文档
- 新功能上线前必须评估是否需要更新合规文档

---

**执行要求**：
本规则优先级极高，与 system-core-rules.md 共同生效。任何可能涉及安全的任务都必须严格遵守本规范。
