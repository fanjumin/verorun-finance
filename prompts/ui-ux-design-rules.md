# 易站智能 - UI/UX 设计规范

**版本**：v2026.05  
**优先级**：高（用户体验与品牌一致性）

平台整体风格为**深色科幻科技风格**，所有前端界面必须严格遵循本规范，保持视觉统一、专业和未来感。

### 1. 整体视觉风格
- **主色调**：深空黑 (#0a0a0a)、电光蓝 (#00f5ff)、紫罗兰 (#a020f0)、霓虹绿 (#00ff9f)
- **辅助色**：白色/浅灰文字、玻璃态（Glassmorphism）效果、微光描边
- **粒子与动态**：适当使用粒子背景、流光效果、平滑过渡动画（但不能影响性能）
- **字体**：科技感字体（Inter / Satoshi / Orbitron 组合）

### 2. 核心 UI 组件规范
- **按钮**：清晰的主次按钮区分，hover 时发光效果
- **卡片**：使用玻璃态卡片（半透明背景 + 模糊 + 描边）
- **表单**：输入框有明显焦点效果 + 帮助说明
- **导航**：侧边栏分组清晰，支持折叠，活跃状态高亮
- **登录/注册**：必须使用统一登录组件，包含 Tab 切换和帮助说明

### 3. 用户体验原则
- 所有关键操作必须添加**帮助说明**（参考 user-flow-help-rules.md）
- 操作反馈及时（加载状态、成功/失败提示、Toast）
- 保持一致性：相同功能在不同页面使用相同组件和文案
- 移动端响应式友好（优先考虑大屏管理后台，也需支持移动）

### 4. 页面布局规范
- **管理后台**：左侧侧边栏 + 顶部 Header + 主要内容区
- **用户后台 (platform)**：现代简洁布局，突出 Agent 矩阵和社区功能
- **信息层级**：重要信息突出显示，使用颜色、徽章、图标辅助

### 5. 生成前端代码时的要求
- 必须使用 Tailwind CSS
- 代码结构清晰，组件化开发
- 动态效果要适度，不能导致页面卡顿
- 必须为用户操作添加清晰的说明文案
- 颜色、间距、圆角等必须与平台整体风格一致

### 6. 修改 UI/UX 时的要求
- 任何界面修改必须先说明设计思路和风格一致性
- 重要页面改动需提供前后对比说明
- 确保修改后不会破坏现有统一登录组件等核心 UI

---

**执行要求**：
本规则与 system-core-rules.md 共同生效。生成或修改任何前端页面、组件时都必须严格遵守本 UI/UX 规范。
