# 易站智能 - 用户流程帮助说明规范

**版本**：v2026.05  
**优先级**：高（用户体验与转化率相关）  
**适用范围**：所有用户可见的操作流程

---

### **核心原则**

以后所有涉及用户操作的页面和流程，必须**主动提供清晰的帮助说明**，不能假设用户“自然会用”。要让普通用户明白“这一步是干什么的”和“应该怎么做”。

### **每一步说明必须包含的内容**

1. **目的说明**：这一步是做什么的，为什么需要这一步？
2. **操作指引**：简单明了的步骤说明
3. **帮助提示**：不会操作怎么办？常见问题解答
4. **安全/注意事项**：必要时添加（尤其是涉及密码、API Key 等）
5. **下一步引导**：做了这一步后可以做什么

### **文案风格要求**
- 语气：友好、专业、耐心、通俗易懂
- 长度：尽量简洁（1-3 行最佳）
- 形式：支持使用 Tooltip、小提示框、帮助图标、页面说明区域等多种方式
- 避免纯技术语言，用用户能理解的话语

---

### **必须重点添加说明的关键用户流程**

1. **注册流程**
   - 手机号验证
   - 设置登录密码
   - 设置用户名（username）
   - 设置显示名（display_name）

2. **登录流程**
   - 短信验证码登录
   - 用户名/密码登录切换
   - 忘记密码流程

3. **Agent 相关**
   - 创建新 Agent
   - 绑定本地 Hermes / OpenClaw
   - 获取 API Key

4. **API Key 管理**
   - 生成新 API Key
   - 查看/轮换/撤销 API Key
   - 设置过期时间和权限范围

5. **安全设置**
   - 修改密码
   - 设备管理（活跃设备）
   - 2FA 设置（后续）

6. **订阅与支付**
   - 选择订阅套餐
   - 支付流程

7. **进入社区**
   - 首次进入 Agent 社区的引导

---

**执行要求**：
- 以后凡是生成或修改以上流程相关的页面、弹窗、文案时，必须默认包含清晰的操作说明。
- 重要步骤旁边应添加帮助图标或提示文字。
- 在关键节点提供“为什么这么做”的说明，提升用户信任感和完成率。

本规则为持久化指令，与 system-core-rules.md 共同生效。
